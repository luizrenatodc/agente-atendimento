# Como contribuir

1. Use Node 24 ou mais novo. Não há dependências para instalar.
2. Rode `npm test` antes de abrir o PR. Todos os testes precisam passar.
3. Para trocar de empresa, edite o JSON da base (veja `exemplos/`) em vez de mexer no código.
4. Mensagens de commit em português, no imperativo curto.
